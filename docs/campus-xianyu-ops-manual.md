# 校园咸鱼 · 操作手册

> 适用系统：Campus Xianyu（校园二手交易 H5）  
> 说明：本文描述本仓库当前真实功能与页面路径，供用户、答辩与 AI 知识库对齐使用。

---

## 1. 系统概览

校园咸鱼面向本校学生，提供二手闲置的发布、浏览、求购、沟通与线下成交闭环。  
默认交易方式为**校内面交**；平台**不托管资金、不代收货款、不提供官方退款通道**。

| 端 | 谁用 | 入口 |
|----|------|------|
| 学生端 | 注册学生 | 登录后底部导航 |
| 管理员端 | 管理员账号 | 登录后自动进入管理界面 |
| AI 客服 | 已登录学生 | 「我的」→ AI 客服 |

技术要点（开发者）：Vue3 前端 + Spring Boot 业务 API + MySQL；AI 为独立 FastAPI/LangGraph 服务（RAG 客服 / 挂牌 / 风控 / 搜商品）。

## 2. 学生端操作

### 2.1 注册与登录
1. 打开站点，进入登录页。  
2. 无账号则注册：用户名、昵称、密码。  
3. 登录成功后进入学生端首页。

### 2.2 实名认证（发布/交易前置）
1. 底部「我的」→「去实名认证」。  
2. 填写学号、学院并提交。  
3. 等待管理员审核。  
4. 通过后可：发布商品、发布求购、留言、私聊、下单。  
未认证时相关按钮会提示先认证。

### 2.3 浏览与搜索商品
1. 底部「首页」。  
2. 可用关键词、分类、校区、成色、价格筛选。  
3. 点击卡片进入详情（图片、描述、卖家、留言、联系、购买）。

### 2.4 发布商品
1. 确认已实名。  
2. 底部「发布」。  
3. 填写标题、价格、分类、成色、校区、交易方式、描述。  
4. 上传 1～9 张图片。  
5. 提交 → 状态「待审核」→ 管理员通过后出现在首页。  
可在「我的」→「我的商品」查看、修改、下架、恢复、删除。

### 2.5 求购
1. 底部「求购」浏览。  
2. 认证后发布求购信息。  
3. 在「我的求购」管理状态（匹配/关闭）。  
4. 详情可联系发布者。

### 2.6 留言与私聊
- 留言：商品详情公开留言区。  
- 私聊：详情「联系卖家/联系发布者」→ 底部「消息」。

### 2.7 下单与双方确认
1. 详情「我要购买」→ 填写见面时间/地点/备注。  
2. 「我的订单」：  
   - 待沟通：双方都确认约定 → 待交易  
   - 待交易：买家确认收货 + 卖家确认完成 → 已完成（商品下架）

### 2.8 举报
在支持举报的入口选择原因并提交，等待管理员处理。

### 2.9 AI 客服
1. 「我的」中打开 AI 客服（对话面板）。  
2. 模式：自动 / 客服 / 挂牌 / 风控。  
3. 示例：  
   - 「如何实名认证」→ RAG 依据知识库回答  
   - 「现在有手机卖吗」→ 搜索在售商品并出卡片  
   - 「出闲置高数第七版…」→ 挂牌文案  
4. 历史按账号保存在浏览器本地；可清空。

## 3. 管理员端操作

### 3.1 实名审核
查看待审学生认证，通过或拒绝（可填备注）。

### 3.2 商品审核
1. 打开待审商品列表。  
2. 可先点「执行 AI 风控审核」：风控 Agent 给出 PASS/REVIEW/REJECT 建议并写日志。  
3. 人工点「通过」或「拒绝」。  
AI 建议仅辅助，最终以人工操作为准。

### 3.3 举报处理
成立则可下架相关商品；驳回则保持上架。

### 3.4 用户与分类
- 用户：可封禁/解封学生账号。  
- 分类：增删改；有关联商品或子分类时需谨慎删除。

## 4. 状态速查

| 对象 | 状态 | 含义 |
|------|------|------|
| 认证 | UNAUTH/PENDING/APPROVED/REJECTED | 未认证/待审/通过/拒绝 |
| 商品 | PENDING/PUBLISHED/REJECTED/OFF_SHELF | 待审/在售/拒审/下架 |
| 求购 | OPEN/MATCHED/CLOSED | 求购中/已匹配/关闭 |
| 订单 | PENDING_CHAT/PENDING_TRADE/COMPLETED | 待沟通/待交易/完成 |
| 风控建议 | PASS/REVIEW/REJECT | 建议通过/复核/拒绝 |

---

## 5. 与 AI 知识库的关系

- RAG 文档：`ai-service/knowledge/faq.md`  
- 客服链路：用户问题 → 检索知识库 → 命中片段 + 原问题 → 大模型作答  
- 搜商品：调用 Java `/api/products`，返回卡片  
- 管理端审核：调用 AI `mode=risk`，不再以关键词规则为主（规则仅作 AI 不可用时的兜底）
